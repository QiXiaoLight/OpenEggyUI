## 🚀 项目简介

OpenEggyUI 是由 **SYSTEM-LIGHT** 个人主导开发的一系列《蛋仔派对》风格桌面美化组件的总称。它源于已正式归档的 EggyUI 项目，在此基础上进行了全面的重构与质量升级。

**项目定位**：一个高质量、模块化的个人向开源美化项目。

## 📜 项目渊源与开发代号

OpenEggyUI 的开发代号 **“Eggix”** 承载着一段社区“野史”：

> 据《蛋仔派对》维基（已删改）的蛋小蓝词条记载：
> “蛋软公司（Eggysoft）的创始人，在贝克实验室开发出 **Eggix 操作系统**，内置 EggyUI 桌面环境，被称为‘蛋仔岛的比尔盖茨’……”

## 🛠️ 为什么要发起 OpenEggyUI 项目

EggyUI 的陨落是一场由技术债务与团队治理溃败共同酿成的悲剧：

- **技术债务**：早期大量使用易语言，导致性能低下、兼容性差、维护困难
- **治理溃败**：缺乏有效决策机制，讨论常沦为情绪宣泄，角色划分不清
- **架构锁定**：转向现代技术栈的成本极高

OpenEggyUI 的建立是一次技术自救与社会重构：抛弃易语言，采用现代化架构，以“个人维护主导，社区贡献为辅”的简洁模式运作。

## ✨ 与 EggyUI 的关系

- **精神续作**：继承了 EggyUI 的美学理念
- **质的飞跃**：代码质量、运行效率、视觉细节均有显著提升
- **个人维护**：由 SYSTEM-LIGHT 独立维护，确保技术路线的纯粹

## ⚙️ 发展与更新模式

- **不定期更新**：以开发者的个人兴趣和可用时间为驱动
- **模块化路线**：组件以独立模块形式发布
- **开源与透明**：所有代码遵循非商业性使用许可
